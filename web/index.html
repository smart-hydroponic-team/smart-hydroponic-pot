Smart Hydroponic Pot

Pionowa doniczka hydroponiczna, którą doglądasz z telefonu.

O projekcie

Smart Hydroponic Pot to pionowa doniczka hydroponiczna, która sama dba o rośliny. System tworzą trzy współpracujące części.

  1. Sterownik ESP

    Odczytuje czujniki i steruje urządzeniem.

  2. Serwer z API

    Gromadzi dane z doniczki i udostępnia je aplikacji.

  3. Aplikacja mobilna

    Pozwala podglądać stan uprawy i nią zarządzać.

Stan prac

  • Model 3D konstrukcjiw trakcie
  • Strona WWWw trakcie
  • Oprogramowanie sterownika (ESP)planowane
  • Serwer i APIplanowane
  • Aplikacja mobilnaplanowane
