Smart Hydroponic Pot

Inteligentna doniczka hydroponiczna – projekt studencki.

O projekcie

Smart Hydroponic Pot to pionowa doniczka hydroponiczna, która sama dba o rośliny. Sterownik oparty na ESP odczytuje czujniki i steruje urządzeniem, serwer z API gromadzi dane, a aplikacja mobilna pozwala podglądać stan uprawy i nią zarządzać.

Stan prac

  • Model 3D konstrukcjiw trakcie
  • Strona WWWw trakcie
  • Oprogramowanie sterownika (ESP)planowane
  • Serwer i APIplanowane
  • Aplikacja mobilnaplanowane
